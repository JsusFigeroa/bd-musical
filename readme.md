**Anotaciones** 
Para poder modificar los datos del artista se hace click derecho sobre la canción.
Sobre el lenguaje de busqueda se utiliza & para imponer dos condiciones (P y Q)
Se utiliza | como un o (P o Q)
Se utiliza ! para la negación (no P)
Se pueden utilizar paréntesis para especificar la jerarquía o se usa la jerarquía por defecto.
Se puede buscar por cualquiera de los elementos de una rola, nombre, año, track, artista, y género.
Un ejemplo de búsqueda es el siguiente:
  artista:"Canserbero" & año:"2012"
Para buscar el artista de nombre Canserbero y del año 2012.
